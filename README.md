# NAI Factory · Hinchil

> NovelAI로 그림을 **만들고(팩토리)**, 그 그림의 노출 부위를 **자동으로 흰칠/모자이크(흰칠)** 해 주는 로컬 도구예요. 두 가지 기능이 한 화면 위쪽 탭으로 이어져 있어요.

- **팩토리**: NovelAI에 여러 캐릭터 × 여러 동작을 차례대로 요청해서 폴더에 바로 저장해요. 만든 그림은 버튼 한 번으로 흰칠 탭으로 넘길 수 있어요.
- **흰칠**: 그림 폴더를 열면 노출 부위를 자동으로 찾아서 흰칠/모자이크한 결과를 별도 폴더에 저장해요. 감지는 **내 PC 안에서만** 돌아가서 그림이 밖으로 나가지 않아요.

> ⚠️ 자동 감지는 완벽하지 않아요. 그림을 공개하기 전에 결과를 **꼭 직접 확인**하세요. (아래 [검수 체크](#검수-체크) 기능이 이 확인을 돕기 위한 거예요.)

## 다운로드와 시작하기

1. 오른쪽 **Releases**에서 최신 `NAI-Factory-Hinchil-v버전-win-x64.zip`(예: `-v1.2.0-`)을 받아요.
2. 압축을 풀어요.
3. `Start NAI Factory.bat`을 **더블클릭**해요. 처음 실행하면 같은 폴더에 아이콘이 붙은 **NAI Factory** 바로가기가 생겨요. 다음부터는 이 바로가기를 눌러도 되고, 바탕화면에 복사해 둬도 돼요. (폴더를 옮기면 바로가기는 다음 실행 때 새 위치로 다시 만들어져요) 검은 창이 뜨는데, 쓰는 동안은 닫지 마세요. (닫으면 꺼져요.) 반대로 **브라우저 창(탭)을 모두 닫으면 검은 창도 몇 초 뒤 저절로 꺼져요.** (폴더 전체 실행 중에는 꺼지지 않아요)
4. 브라우저가 자동으로 열려요. 안 열리면 검은 창에 적힌 주소(보통 `http://127.0.0.1:5177`)를 주소창에 입력해요.
5. 흰칠 탭 왼쪽 아래 칩이 **"모델 준비됨"** 인지 확인하면 끝!

**필요한 것**

| 항목 | 내용 |
| --- | --- |
| 운영체제 | Windows 64비트 |
| 설치할 것 | **없어요.** 휴대용 zip에는 Node.js, 필요한 패키지, 감지 모델이 모두 들어 있어요 |
| 인터넷 | 흰칠은 **필요 없어요**. 팩토리 탭은 NovelAI와 통신하므로 필요해요 |
| NovelAI 계정 | 팩토리 탭을 쓸 때만 필요해요 (API 키) |

화면 위쪽 제목줄의 **팩토리 | 흰칠** 탭으로 두 기능을 오갈 수 있어요. 처음 보이는 화면이 팩토리이고, 흰칠 탭의 주소는 `http://127.0.0.1:5177/censor` 예요.

## 처음 켰을 때 (기본 폴더)

새 PC에서 처음 켜면 폴더가 이렇게 잡혀 있어요. 전부 **앱 폴더(압축을 푼 폴더) 기준 상대경로**라서, 폴더를 어디로 옮겨도 그대로 돌아가요.

| 위치 | 기본값 | 의미 |
| --- | --- | --- |
| 팩토리 탭 → 저장 폴더 | `생성` | 만든 그림이 저장되는 곳 |
| 흰칠 탭 → 그림 폴더 | `생성` | 팩토리 탭이 만든 그림이 바로 흰칠 대상이 돼요 |
| 흰칠 탭 → 결과 폴더 | `생성/output` | "원본/output" 체크 상태 |

- `생성` 폴더는 없으면 **자동으로 만들어져요.**
- 이 기본값은 **처음 한 번만** 적용돼요. 한 번 폴더를 고르면 다음에 켤 때도 그 폴더를 기억해요. (`캐시/last-folders.json`)
- 다른 폴더(예: `D:\그림\생성`)를 쓰려면 **찾기** 버튼으로 고르거나 경로를 직접 입력하면 돼요. 입력칸 아래에 **실제로 저장되는 위치**가 표시돼요.

## 팩토리 탭

NovelAI로 **캐릭터 × 동작**의 모든 조합을 차례대로 만들어서 폴더에 저장해요.
예를 들어 캐릭터 3명 × 동작 10개를 체크하면 30장을 순서대로 만들어요.

### 1. API 키 넣기

- 왼쪽 위 **NovelAI 키**에 API 키(`pst-`로 시작)를 넣어요. 넣는 즉시 저장돼요.
- 키는 **이 브라우저(localStorage)에만** 저장돼요. 파일로 남지 않고, NovelAI로 요청을 보낼 때만 써요. ([자세히](#개인정보와-보안))
- `보기` / `숨기기`로 입력값을 확인하고, `지우기`로 삭제해요.

### 2. 저장 폴더

- 기본값은 `생성` (앱 폴더 안). 입력칸 아래에 **실제 저장 위치**가 보여요.
- `찾기`로 다른 폴더를 고르거나, `폴더 열기`로 탐색기에서 열어요.
- 폴더가 없으면 자동으로 만들어요.
- ⚠️ 기본값 `생성`은 **앱 폴더 안**이에요. 앱 폴더를 지우거나 새 버전으로 통째로 교체하면 만든 그림도 같이 사라지니, 오래 두고 싶은 그림은 `찾기`로 **앱 폴더 밖**(예: 내 문서나 사진 폴더)을 지정하거나 다른 곳으로 옮겨 두세요.

### 3. 공통 프롬프트

| 칸 | 설명 |
| --- | --- |
| 작가 태그 | 메인 프롬프트 **맨 앞**에 붙어요. 모든 그림에 공통으로 적용돼요 |
| 공통 네거티브 | 모든 그림에 공통으로 들어가는 네거티브 프롬프트 |

### 4. 생성 설정

| 항목 | 선택지 / 설명 |
| --- | --- |
| 모델 | V4.5 Full / V4.5 Curated / V5 Full / V5 Curated |
| 크기 | 세로 832×1216 / 가로 1216×832 / 정사각 1024×1024 |
| 샘플러 | Euler Ancestral(기본) / Euler / DPM++ 2S Ancestral / DPM++ 2M / DPM++ SDE |
| 스텝 | 기본 28 |
| 프롬프트 가이던스 | 기본 6 |
| 가이던스 리스케일 | 기본 0.1 |
| 네거티브 프리셋 | Heavy(기본) / Light / Human Focus / None |
| 품질 태그 추가 | `very aesthetic, masterpiece, no text` 를 자동으로 붙여요. V5에서는 아래에 **Standard / Light**(`very aesthetic, amazing quality, no text`)를 고를 수 있어요 |
| Variety+ | 다양성을 높여요. **V4.5에서만** 쓸 수 있고, V5를 고르면 잠겨요 |

> 품질 태그를 자동으로 붙여 주기 때문에, **캐릭터/동작 칸에는 품질 태그를 넣지 않아도 돼요.**

### 5. 생성 순서와 간격

- **생성 순서**
  - *동작 기준*: 동작1 → (캐릭터 전원) → 동작2 → … 순서로 만들어요.
  - *캐릭터 기준*: 캐릭터1 → (동작 전부) → 캐릭터2 → … 순서로 만들어요.
- **장 사이 쉬는 시간**: 초 단위로 직접 정하거나, **0.1~2초 무작위**로 쉬어요. (요청이 너무 빠르면 막히는 걸 피하려고요)

### 6. 캐릭터 카드

각 카드에는 이런 칸이 있어요.

| 칸 | 설명 |
| --- | --- |
| 이름 | 파일 이름에 쓰여요 |
| 메인 프롬프트 추가 | 작가 태그 뒤에 붙는 공통 부분 (`1girl, solo` 등) |
| 외형 태그 | 캐릭터 프롬프트. 표정/동작 없이 **고정된 외형**만 넣으면 어떤 장면에서도 같은 캐릭터가 나와요 |
| 개별 네거티브 | 이 캐릭터에만 적용되는 네거티브 |
| 시드 | 비우면 무작위. 정하면 그 캐릭터는 같은 시드를 써요 |

카드 머리의 버튼:

- **체크박스** — 이번 생성에 포함할지
- **▾ / ▸** — 접기/펴기
- **▲ ▼** — 순서 바꾸기
- **⧉** — 복제 (이름에 "복사"가 붙어요)
- **✕** — 삭제 (전부 지워서 비워 둘 수도 있어요. 캐릭터가 하나도 없으면 **테스트 1장**과 **전체 생성** 버튼이 막혀요)

### 7. 동작 카드

동작마다 **이름**과 **동작 태그**를 적어요. 캐릭터 카드와 같은 버튼(체크, 접기, 순서, 복제, 삭제)이 있어요.

### 8. 목록 관리

캐릭터 목록과 동작 목록 위쪽 버튼으로:

| 버튼 | 설명 |
| --- | --- |
| 불러오기 | TXT 파일에서 목록을 불러와요 |
| 저장 | 지금 목록을 TXT로 내려받아요 |
| 전체 해제 / 전체 선택 | 체크를 한 번에 바꿔요 |
| + 추가 | 새 카드를 추가해요 |

**TXT 형식**은 이렇게 `[이름]` 아래에 줄을 적어요.

```
[인사하기]
캐릭터 1: smiling, waving hand, upper body

[앉기]
캐릭터 1: sitting on chair, looking at viewer
```

- 동작 TXT는 **배치 생성기 메모장과 같은 형식**이에요. 여러 명이 든 메모장을 불러오면 **캐릭터 1 줄만** 가져오고 알려 줘요.
- 입력한 내용은 브라우저에 자동 저장돼서, 창을 닫았다 열어도 그대로예요.

### 9. 그림에서 태그 가져오기

NovelAI에서 받은 PNG의 메타데이터를 읽어 와서, NovelAI의 "Import Metadata"처럼 **고른 항목만 그대로** 가져와요. 다만 품질 태그와 네거티브 프리셋 글자만은 빼고 가져와요.

- **사용법**: 팩토리 탭에 PNG를 **끌어다 놓거나**, 위쪽 **🖼 그림에서 태그 가져오기** 버튼으로 파일을 골라요.
- **고를 수 있는 항목**: 메인 프롬프트 / 네거티브 / 캐릭터 프롬프트 / 설정 / 시드 / 실제 프롬프트 (그림에 없는 항목은 흐리게 표시돼요)
- **들어가는 곳**
  - 메인 프롬프트 → 왼쪽 **작가 태그** 칸 (원래 있던 내용은 이 그림의 내용으로 바뀌어요)
  - 캐릭터 프롬프트 → **새 캐릭터 카드로 자동 추가돼요.** 기존 카드는 그대로 두고, 캐릭터마다 카드가 하나씩 만들어져 **외형**·**네거티브** 칸에 들어가요 (카드 이름은 파일 이름).
  - 네거티브 → **공통 네거티브**를 이 값으로 바꿔요
  - 설정 → 스텝, 프롬프트 가이던스, 리스케일, 샘플러, 크기(목록에 있는 크기만), 네거티브 프리셋
  - 시드 → 새로 만든 캐릭터 카드의 시드 칸 (메인이나 캐릭터 프롬프트도 같이 골라야 해요)
- **실제 프롬프트**: 랜덤 프롬프트(`||a|b||`)를 쓴 그림에는 "입력한 원본"(랜덤 문법 그대로)과 "실제로 뽑힌 결과"가 따로 저장돼 있어요. 이 항목을 켜면 뽑힌 결과만 가져오고, 끄면(기본) 원본을 가져와요. 랜덤 프롬프트를 안 쓴 그림은 두 값이 같아서 선택할 수 없어요.
- **품질 태그와 네거티브 프리셋은 글자를 빼고, 설정으로 옮겨요**: 팩토리는 생성할 때 품질 태그(`very aesthetic, masterpiece, no text` 등)와 네거티브 프리셋 글자를 자동으로 붙여요. 그림 프롬프트에 이미 들어 있는 걸 그대로 가져오면 다시 생성할 때마다 쌓이니까, 글자는 빼고 대신 **"품질 태그 추가" 켬/끔(V5는 Standard/Light까지)**과 **네거티브 프리셋(Heavy/Light/Human Focus/None/Furry Focus)**을 그림에 맞춰 바꿔요. NovelAI 사이트 그림에는 켬/끔 표시가 따로 없어서, 프롬프트에 그 글자가 들어 있었는지로 알아내요. 메인 프롬프트를 고르면 품질 태그, 네거티브를 고르면 프리셋이 따라가요. 사이트가 프리셋 앞에 붙이는 `nsfw`도 같이 빼요. 이미 쌓여 있는 칸도 생성할 때 한 번만 붙도록 정리해요.
- **읽는 방식**: PNG 안의 텍스트 정보와, NovelAI가 알파 채널에 숨겨 두는 정보 **둘 다** 지원해요.
- 작가 태그 같은 나머지 태그는 그대로 들어와요. 필요 없으면 직접 지워 주세요.
- ⚠️ **동작 태그는 자동으로 나눠지지 않아요.** 그림에 든 포즈/표정 같은 동작은 외형으로 가져온 뒤 **직접 지우고 동작 카드로 옮겨** 주세요.
- 태그가 없는 그림(흰칠 탭이 메타데이터를 지운 결과물, 다른 서비스를 거쳐 다시 저장된 그림, JPG/WebP)은 "찾지 못했어요"라고 알려 줘요.

### 10. 만들기

아래쪽 바에서:

- **요약**: `캐릭터 N × 동작 M = K장` 을 보여줘요.
- **테스트 1장**: 체크된 첫 캐릭터로 동작 없이 한 장만 만들어 봐요. 키와 설정이 맞는지 확인할 때 좋아요.
- **전체 생성**: 모든 조합을 순서대로 만들어요. (30장 이상이면 시작 전에 한 번 확인해요)
- **중단**: 지금 만드는 장까지만 받고 멈춰요.
- **진행률 / 결과 줄**: 만든 그림이 썸네일로 쌓여요. 클릭하면 크게 보고, 좌우 화살표로 넘겨요.
- **폴더 열기**: 저장 폴더를 탐색기에서 열어요.

### 11. 파일 이름 규칙

저장 파일 이름은 **`캐릭터이름_동작이름.png`** 로 통일돼요.

- 이미 같은 이름이 있으면 **뒤에 `(1)`, `(2)` …** 가 붙어요. 예: `아리_인사.png`, `아리_인사(1).png`, `아리_인사(2).png`
- 기존 파일은 **절대 덮어쓰지 않아요.**
- 파일 이름에 못 쓰는 글자는 `_`로 바뀌어요. 한글, 영문, 숫자, `_`, `-` 는 그대로 써요.
- 시드는 파일 이름에 넣지 않아요. 결과 줄에서 확인할 수 있어요.

### 12. 오류가 났을 때

| 상황 | 동작 |
| --- | --- |
| 서버가 바쁘거나 요청이 몰림 (429 등) | 5초 × 횟수만큼 쉬었다가 **같은 장을 같은 시드로** 다시 시도해요 |
| 연속 3번 실패 | 멈춰요 |
| 키/구독 문제 (401, 402, 403) 또는 잘못된 요청 (400) | 해결되지 않는 오류라 **바로 멈추고** 이유를 알려 줘요 (401: 키 확인, 402: Anlas/구독 확인) |
| 응답이 3분을 넘김 | 시간 초과로 처리해요 |
| 생성 중에 창을 닫으려 할 때 | 경고가 떠요 |

## 흰칠 탭

### 기본 흐름

1. **폴더 고르기** — 그림 폴더(가릴 그림)와 결과 폴더(원본과 다른 곳)를 정해요.
2. **자동 미리 스캔** — 폴더를 열면 모든 그림을 자동으로 스캔해서 오른쪽 목록에 `N곳`(감지 있음) 또는 `없음`을 표시해요.
3. **미리보기와 조정** — 목록에서 그림을 눌러 결과를 확인하고, 슬라이더와 옵션을 바꾸면 결과가 바로 바뀌어요.
4. **저장** — `이 그림 저장` 또는 `폴더 전체 실행`.
5. **확인** — 끝나면 결과 폴더의 `결과보고.txt`에서 "감지 없음" 목록을 눈으로 확인해요.

### 폴더

- **하위 폴더까지**: 목록, 미리 스캔, 폴더 전체 실행에 모두 적용돼요.
- **원본/output**: 체크하면 결과 폴더가 그림 폴더 안의 `output` 폴더로 자동 지정돼요. (없으면 만들어요)
- 원본 그림은 **절대 건드리지 않아요.** 결과는 항상 별도 폴더에 저장돼요.

### 가리는 방식

| 옵션 | 설명 |
| --- | --- |
| 방식 | **흰칠** / **모자이크** |
| 모양 | **원형**(감지 박스를 감싸는 타원, 가장자리가 부드러워요) / **사각형** |
| 칠할 색 | 흰칠 색을 바꿀 수 있어요 (기본 흰색) |

### 감지 설정

| 옵션 | 설명 |
| --- | --- |
| **민감도(임계값)** | 낮을수록 더 많이 잡아요. 놓치면 내리고, 엉뚱한 데를 가리면 올려요 |
| **가림 크기 조절** | 0%가 기본. 마이너스로 내리면 감지 박스보다 더 작게, 올리면 더 크게 가려요 |
| **가장자리 번짐** | 가린 부분의 가장자리를 얼마나 부드럽게 할지 |

### 가릴 부위

애니 그림용 감지 모델이 찾는 부위를 골라요.

- 유두(여)
- 성기(여)
- 성기(남)

체크를 끈 부위는 가리지 않아요.

### 박스 편집

자동 감지가 틀렸을 때 직접 고칠 수 있어요. 화면 위쪽 **결과 / 원본 / 박스 편집** 중 **박스 편집**을 눌러요.

- **빨간 박스를 클릭** → 그 박스를 제외해요 (가리지 않음)
- **빈 곳을 드래그** → 가릴 영역을 직접 추가해요
- **수정 되돌리기** → 그 그림의 편집을 처음 상태로 돌려요

### 검수 체크

"이 그림은 내가 확인했다"를 표시하는 기능이에요. 단축키는 **V** 예요.

- 누르면 그 그림이 (제외한 박스, 직접 그린 박스 **그대로**) 결과 폴더에 저장되고, 고친 내용도 기억해요.
- 버튼은 **검수 체크 (V)** → 이미 검수한 그림에서는 **✓ 검수 완료 (V: 취소)** 로 바뀌어요.
- 검수 표시는 저장돼요. 다음에 켜도 남아 있어요.
- 오른쪽 목록의 **체크박스**로, 그림을 열지 않고도 바로 검수 체크할 수 있어요.
- 목록 위 드롭다운으로 **검수 안 한 것만** 골라 볼 수도 있어요.
- **다음 그림으로 자동 이동**: 검수 체크를 누르면 다음 그림으로 넘어가요. (이미 검수한 그림은 건너뛰어요) 실행 옵션에서 끌 수 있어요.

### 실행 옵션

| 옵션 | 설명 |
| --- | --- |
| 폴더를 열면 자동으로 미리 스캔 | CPU를 조금 써요. 결과가 저장돼서 다음엔 바로 떠요. 부담되면 끄세요 |
| 메타데이터 유지 | 끄면(기본) 결과 그림에서 프롬프트/시드가 **지워져요.** 켜면 PNG의 텍스트 메타데이터를 그대로 옮겨요. (NAI가 픽셀에 숨겨 넣는 정보는 어느 쪽이든 남지 않아요) |
| 검수 체크하면 다음 그림으로 이동 | 위의 자동 이동 |
| 검수 체크한 그림은 건너뛰기 | 폴더 전체 실행 때 이미 검수한 그림을 제외해요 |
| 이미 처리한 파일은 건너뛰기 | 결과 폴더에 이미 있는 파일은 다시 처리하지 않아요 |
| 확인용 박스 그림도 저장 | 결과 폴더 안 `_debug`에 감지 박스를 그린 그림을 같이 저장해요 |

흰칠 옵션(방식, 모양, 민감도, 부위 등)은 바꾸는 즉시 이 브라우저에 자동 저장돼서 다음에도 유지돼요. (`config.json`을 직접 만들어 두면 처음 기본값으로 쓰여요.)

### 폴더 전체 실행

- 아래쪽 **폴더 전체 실행** 버튼으로 그림 폴더 전체를 한 번에 처리해요. 진행률과 로그를 볼 수 있어요.
- 끝나면 **결과 폴더 열기**로 바로 열 수 있어요.
- 결과 폴더에 `결과보고.txt`가 만들어져요. **"감지 없음"으로 나온 그림은 한 번씩 눈으로 확인**하세요. 감지가 놓친 그림일 수 있어요.

- 팩토리 탭의 캐릭터/동작/설정 값도 이 브라우저에만 저장돼요. (브라우저 데이터를 지우면 사라지니, 중요한 목록은 TXT로 저장해 두세요)

## 자주 묻는 질문 / 문제 해결

**Q. 브라우저가 안 열려요.**
주소창에 `http://127.0.0.1:5177` 을 직접 입력해 보세요. 검은 창이 켜져 있어야 해요.

**Q. 검은 창을 닫았는데 브라우저 탭이 그대로 남아 있어요.**
웹페이지는 스스로 탭을 닫을 수 없어요. 대신 서버가 꺼진 걸 알아채면 화면에 "NAI Factory · Hinchil이 꺼졌어요. 이 탭을 닫아 주세요" 안내가 떠요. 탭은 직접 닫아 주세요.

**Q. 브라우저를 닫아도 검은 창이 안 꺼져요 / 반대로 열어 둔 채 꺼져 버렸어요.**
브라우저 창이 닫히면 몇 초 뒤 자동으로 꺼지는데, 브라우저가 "절전 탭"으로 재워 둔 탭은 신호를 못 보내 5분쯤 뒤에 꺼질 수 있어요. 그럴 땐 `Start NAI Factory.bat`(또는 NAI Factory 바로가기)을 다시 켜면 돼요. (입력해 둔 값은 그대로 남아 있어요.) 자동 종료를 끄고 싶으면 `Start NAI Factory.bat`의 `gui-server.js` 뒤에 ` --keep-alive`를 붙이세요.

**Q. 이미 켜져 있다고 나와요 / 5177을 쓰고 있다고 나와요.**
주소는 **5177로 고정**이에요. (브라우저는 주소마다 저장 공간이 따로라서, 포트가 바뀌면 API 키와 팩토리 입력값이 사라져 보이거든요.)
- 같은 폴더의 NAI Factory · Hinchil이 이미 켜져 있으면, 그 창으로 바로 열어 주고 새 검은 창은 끝나요.
- **다른 폴더의** NAI Factory · Hinchil이 켜져 있으면(예: 예전 버전 폴더), 그 검은 창을 먼저 닫고 다시 실행해 주세요.
- 이 프로그램이 아닌 다른 프로그램이 5177을 쓰고 있으면, 그 프로그램을 끄고 다시 실행해 주세요.

**Q. "모델 준비됨"이 안 떠요.**
`models/` 폴더에 `censor_detect_v1.0_s.onnx` 가 있는지 확인해 보세요. (휴대용 zip에는 들어 있어요)

**Q. 감지가 안 돼요 / 엉뚱한 곳을 가려요.**
**민감도**를 조절해 보세요. 놓치면 낮추고, 엉뚱한 데를 가리면 올려요. 안 되면 **박스 편집**으로 직접 고쳐요.

**Q. 생성이 바로 멈춰요 (401 / 402 / 403).**
키가 틀렸거나, Anlas/구독이 부족하거나, 계정 문제일 수 있어요. NovelAI에서 키를 다시 확인해 주세요.

**Q. "이 그림에서 태그를 찾지 못했어요"가 떠요.**
흰칠 탭 결과물(메타데이터 삭제), 디스코드/SNS 등을 거친 그림, JPG/WebP에는 태그가 없어요. NovelAI에서 받은 원본 PNG를 쓰세요.

**Q. 폴더를 옮기고 싶어요.**
휴대용 zip은 통째로 옮겨도 돼요. 기본 폴더는 상대경로라서 같이 따라가요. 직접 고른 절대경로(`D:\...`)는 다시 골라야 할 수 있어요.

**Q. 처음 상태로 돌리고 싶어요.**
흰칠 탭 왼쪽 맨 아래 **완전 초기화** 버튼을 누르세요. 확인 창에서 한 번 더 물어봐요.

- 지워지는 것: 미리 스캔 결과(캐시), 마지막에 쓴 폴더 기억, 저장한 설정(`config.json`), 검수 체크 표시와 고친 박스 기록, 팩토리 탭에 입력한 내용(**API 키, 캐릭터, 동작, 설정**)
- 안 지워지는 것: **그림 파일과 결과 폴더**
- 폴더 전체 실행 중에는 누를 수 없어요. 끝나거나 멈춘 뒤에 눌러 주세요.
- 초기화하면 처음 켠 것처럼 기본 폴더(`생성`, `생성/output`)로 돌아가요.
