# 흰칠

NAI 그림의 노출 부위를 **자동으로 흰칠/모자이크**해 주는 로컬 도구예요.
감지는 내 PC에서만 돌아가서 그림이 밖으로 나가지 않아요.

> 자동 감지는 완벽하지 않아요. 공개하기 전에 결과를 꼭 직접 확인하세요.

## 다운로드

오른쪽 **Releases**에서 최신 `hinchil.zip`을 받아요.

## 필요한 것

- Windows PC
- [Node.js](https://nodejs.org) LTS 버전
- 인터넷 (처음 한 번, 패키지 설치와 모델 내려받기용)

## 쓰는 법

1. 압축을 풀고 `start-gui.bat`을 더블클릭해요. 처음엔 패키지 설치 때문에 1~3분 걸려요.
   (검은 창은 쓰는 동안 닫지 마세요.)
2. 브라우저가 열리면 "그림 폴더"와 "결과 폴더"를 골라요. 안 열리면 `http://127.0.0.1:5177`로 들어가요.
3. 목록에서 그림을 눌러 미리보기하고, 가리는 방식/크기/부위를 바꿔 가며 확인해요.
4. 확인이 끝난 그림은 **검수 체크(V)** 를 누르면 저장돼요. 끝나면 폴더 전체 실행을 해요.

자세한 사용법은 압축 파일 안의 `README.txt`에 있어요.

## 특징

- 원본은 건드리지 않고, 결과는 별도 폴더에 저장
- 흰칠 / 모자이크, 원형 / 사각형, 가장자리 번짐, 가림 크기 조절
- 박스 편집(제외 / 직접 추가), 검수 체크, 미리 스캔 캐시
- 결과에서 프롬프트/시드 메타데이터 제거(기본)

## 감지 모델과 라이선스

압축 파일에는 감지 모델이 들어 있지 않고, 처음 필요할 때 자동으로 내려받아요.

- 애니 그림용: [deepghs/anime_censor_detection](https://huggingface.co/deepghs/anime_censor_detection) (모델 페이지에 MIT로 표시)
- 항문 등: [NudeNet](https://github.com/notAI-tech/NudeNet) 3.4.2 (라이선스 표기가 MIT와 AGPL-3.0으로 엇갈려 있어요. 쓰기 전에 원 저장소에서 조건을 확인해 주세요.)
