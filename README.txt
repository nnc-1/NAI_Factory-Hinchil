흰칠 - NAI 그림의 노출 부위를 자동으로 흰칠/모자이크하는 도구

[필요한 것]
- Windows PC
- Node.js (https://nodejs.org 에서 LTS 버전 설치)
- 인터넷 (처음 한 번, 패키지 설치와 모델 내려받기용)

[쓰는 법]
1. 압축을 풀어요.
2. start-gui.bat 을 더블클릭해요. 처음 한 번은 패키지 설치 때문에 1~3분 걸려요.
   (검은 창은 쓰는 동안 닫지 마세요. 닫으면 꺼져요.)
3. 브라우저가 열리면 왼쪽 아래 칩이 "모델 준비됨"인지 확인해요.
   안 열리면 주소창에 http://127.0.0.1:5177 을 입력해요.
4. "그림 폴더"와 "결과 폴더"(원본과 다른 곳)를 찾기 버튼으로 골라요.
   한 번 고른 폴더는 다음에 켜도 기억해요.
   "원본/output"을 체크하면 결과 폴더가 그림 폴더 안 output 폴더로 자동 지정돼요(없으면 만들어요).
   "하위 폴더까지"는 목록, 미리 스캔, 폴더 전체 실행에 모두 적용돼요.
5. 폴더를 열면 모든 그림을 자동으로 미리 스캔해서, 목록에 "N곳"(감지 있음) 또는
   "없음"이 표시돼요. 위쪽 드롭다운으로 감지 있음/없음만 골라 볼 수도 있어요.
   (스캔 결과는 캐시 폴더에 저장돼서 다음엔 바로 떠요. 스캔이 부담되면 "폴더를 열면
   자동으로 미리 스캔"을 꺼요.)
6. 목록에서 그림을 눌러 미리보기하고, 아래 항목을 바꿔 가며 확인해요.
   - 가리는 방식: 흰칠 / 모자이크, 모양: 원형 / 사각형
   - 민감도, 가림 크기 조절(마이너스면 더 작게), 가장자리 번짐
   - 가릴 부위: 유두(여), 성기(여), 성기(남), 항문 (NudeNet 부위는 따로 펼쳐서 선택)
   - 박스 편집: 빨간 박스 클릭 = 제외, 빈 곳 드래그 = 가릴 영역 추가
   - 이 그림 저장 / 폴더 전체 실행
   - 검수 체크(단축키 V): 확인이 끝난 그림에 표시해요. 체크하면 그 그림이 (제외한 박스, 직접 그린 박스
     그대로) 결과 폴더에 저장되고, 고친 내용도 기억해요. 표시는 저장되고, 폴더 전체 실행에서 건너뛰어요
     (실행 옵션에서 끌 수 있어요). 목록 위 드롭다운으로 검수 안 한 것만 볼 수도 있고,
     오른쪽 목록의 체크박스로 그림을 열지 않고도 바로 체크할 수 있어요.
     검수 체크를 누르면 다음 그림으로 넘어가요(이미 검수한 그림은 건너뜀). 실행 옵션에서 끌 수 있어요.
7. 끝나면 결과 폴더의 결과보고.txt에서 "감지 없음" 목록을 눈으로 확인해요.

[알아둘 것]
- 자동 감지는 완벽하지 않아요. 공개하기 전에 결과를 꼭 직접 확인하세요.
- 원본 그림은 건드리지 않고, 결과는 별도 폴더에 저장돼요.
- 감지는 내 PC에서만 돌아가요. 그림이 밖으로 나가지 않아요. 인터넷은 처음 패키지를 설치하고 모델을 받을 때만 써요.
- "메타데이터 유지"를 끄면(기본) 결과 그림에서 프롬프트/시드가 지워져요. 켜면 PNG의 텍스트
  메타데이터를 그대로 옮겨요. (NAI가 픽셀에 숨겨 넣는 정보는 남지 않아요.)
- 설정 저장 버튼을 누르면 config.json이 만들어져요. 자동 스캔 결과와 마지막 폴더는 캐시 폴더에 저장돼요.
- 감지하는 동안 CPU를 코어의 절반쯤 써요.

[감지 모델과 라이선스]
이 압축 파일에는 감지 모델이 들어 있지 않아요. 처음 필요할 때 자동으로 내려받아요(인터넷 필요).
- 애니 그림용 모델 (유두/성기, 기본): models/censor_detect_v1.0_s.onnx, 약 45MB.
  deepghs/anime_censor_detection (https://huggingface.co/deepghs/anime_censor_detection),
  모델 페이지에 MIT 라이선스로 표시돼 있어요. NOTICE-anime-censor.txt 참고.
  자동으로 안 받아지면 아래 주소에서 직접 받아 이 이름으로 models 폴더에 넣어요.
  https://huggingface.co/deepghs/anime_censor_detection/resolve/main/censor_detect_v1.0_s/model.onnx
- NudeNet 모델 (항문 등, "항문"을 고를 때만 사용): models/320n.onnx, 약 12MB.
  NudeNet 3.4.2 (https://github.com/notAI-tech/NudeNet) 의 모델이에요. GitHub에서 안 받아지면
  PyPI의 nudenet 패키지에서 같은 파일을 꺼내 써요.
  NudeNet 쪽은 라이선스 표기가 MIT와 GNU AGPL-3.0으로 엇갈려 있어요.
  쓰기 전에 원 저장소에서 라이선스 조건을 확인해 주세요.
