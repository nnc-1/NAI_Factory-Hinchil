NAI Factory · Hinchil - NovelAI로 그림을 만들고(팩토리), 노출 부위를 자동으로 흰칠/모자이크하는(흰칠) 도구

[필요한 것]
- Windows 64비트 PC
- 아무것도 설치할 필요 없어요. (Node.js, 패키지, 감지 모델이 모두 들어 있어요)

[시작하기]
1. 압축을 먼저 풀어요. (zip 안에서 바로 실행하면 안 돼요)
2. "Start NAI Factory.bat" 을 더블클릭해요.
   - 처음 실행하면 같은 폴더에 아이콘이 붙은 "NAI Factory" 바로가기가 생겨요. 다음부터는 이걸 눌러도 되고, 바탕화면에 복사해 둬도 돼요.
   - 검은 창은 쓰는 동안 닫지 마세요. 닫으면 꺼져요.
   - 브라우저를 닫아도 검은 창은 저절로 꺼지지 않아요. 다 쓰고 나면 직접 닫으세요.
     (다시 열려면 http://127.0.0.1:5177 로 들어가거나 바로가기를 한 번 더 누르세요)
3. 브라우저가 자동으로 열려요. 안 열리면 주소창에 http://127.0.0.1:5177 을 입력해요.
   (주소는 5177 하나로 고정이에요. 이미 켜져 있으면 열려 있는 창으로 이동해 줘요.)
4. 화면 위쪽 제목줄의 "팩토리 | 흰칠" 탭으로 두 기능을 오가요.
   흰칠 탭 왼쪽 아래의 칩이 "모델 준비됨"이면 준비 끝이에요.
5. Windows SmartScreen 경고가 뜨면 "추가 정보" → "실행"을 눌러요. 일부 백신이 오탐할 수 있어요.

[팩토리 탭 - NovelAI로 그림 만들기]
- 켜면 처음 보이는 화면이에요. (주소: http://127.0.0.1:5177)
- NovelAI API 키(pst-로 시작)를 넣으면 이 브라우저에만 저장돼요. 파일로 남지 않고, NovelAI로 요청할 때만 쓰여요.
- 키 아래에 V5 잔여량(%)과 Anlas가 보여요. 그림을 한 장 만들 때마다 갱신되고, 새로고침 버튼도 있어요.
- 저장 폴더를 고르면 만드는 그림이 그 폴더에 바로 저장돼요. 처음엔 앱 폴더 안 "생성" 폴더를 제안해요.
  (앱 폴더를 지우거나 새 버전으로 교체하면 그 안의 그림도 사라져요. 오래 둘 그림은 앱 폴더 밖 폴더를 지정하거나 옮겨 두세요.)
- 파일 이름은 "캐릭터이름_동작이름.png" 이고, 겹치면 (1), (2)가 붙어요.
- 캐릭터와 동작을 여러 개 만들어 체크하면 "캐릭터 N × 동작 M"장을 차례대로 만들어요.
  캐릭터/동작 카드는 전부 지워서 비워 둘 수도 있어요. (캐릭터가 하나도 없으면 생성 버튼이 막혀요)
- 설정: 작가 태그, 공통 네거티브, 모델(V4.5/V5), 크기, 샘플러, 스텝, 가이던스, 리스케일,
  네거티브 프리셋, 품질 태그(V5는 Standard/Light), Variety+(V4.5에서만), 생성 순서, 장 사이 쉬는 시간
- 그림에서 태그 가져오기: NovelAI PNG를 화면에 끌어다 놓거나 위쪽 "그림에서 태그 가져오기"를 눌러요.
  메인 프롬프트(작가 태그 칸으로) / 네거티브 / 캐릭터 프롬프트(새 카드로 추가) / 설정 / 시드 / 실제 프롬프트를
  고른 대로 그대로 가져와요. "실제 프롬프트"를 켜면 랜덤 프롬프트(||a|b||)에서 뽑힌 결과만 가져와요.
  품질 태그와 네거티브 프리셋 글자는 생성할 때 자동으로 붙으니, 쌓이지 않게 글자는 빼고
  "품질 태그 추가"와 네거티브 프리셋 설정을 그림에 맞춰 바꿔요. (메인 프롬프트/네거티브를 고르면 따라가요)
  그림에 든 포즈/표정 같은 동작 태그는 자동으로 나뉘지 않으니 필요하면 직접 동작 카드로 옮겨 주세요.
- 생성된 그림은 화면 아래에 쌓이고, 새로 생성해도 지워지지 않아요. "미리보기 지우기"로 직접 지워요.
  (저장된 그림 파일은 그대로예요)
- 캐릭터 목록과 동작 목록은 TXT로 저장/불러오기를 할 수 있어요. (동작 TXT는 배치 생성기 메모장과 같은 형식)
- 같은 시드로 다시 시도, 요청이 몰리면(429) 쉬었다 재시도, 키/구독 문제(401~403)면 바로 멈춰요.
- 다 만들면 "이 폴더 흰칠하러 가기"를 눌러서 바로 흰칠 탭으로 넘어가요.
- 생성에는 인터넷이 필요해요. (흰칠은 인터넷 없이 돼요)

[흰칠 탭 - 노출 부위 자동 흰칠/모자이크]
1. 처음엔 그림 폴더가 앱 폴더 안 "생성"(팩토리 탭이 그림을 저장하는 곳), 결과 폴더는 그 안 "output"으로 잡혀 있어요.
   다른 곳을 쓰려면 "그림 폴더"와 "결과 폴더"(원본과 다른 곳)를 찾기 버튼으로 골라요.
   한 번 고른 폴더는 다음에 켜도 기억해요.
   "원본/output"을 체크하면 결과 폴더가 그림 폴더 안 output 폴더로 자동 지정돼요(없으면 만들어요).
   "하위 폴더까지"는 목록, 미리 스캔, 폴더 전체 실행에 모두 적용돼요.
2. 폴더를 열면 모든 그림을 자동으로 미리 스캔해서, 목록에 "N곳"(감지 있음) 또는
   "없음"이 표시돼요. 위쪽 드롭다운으로 감지 있음/없음만 골라 볼 수도 있어요.
   (스캔 결과는 캐시 폴더에 저장돼서 다음엔 바로 떠요. 스캔이 부담되면 "폴더를 열면
   자동으로 미리 스캔"을 꺼요.)
3. 목록에서 그림을 눌러 미리보기하고, 아래 항목을 바꿔 가며 확인해요.
   - 가리는 방식: 흰칠 / 모자이크, 모양: 원형 / 사각형
   - 민감도, 가림 크기 조절(마이너스면 더 작게), 가장자리 번짐
   - 가릴 부위: 유두(여), 성기(여), 성기(남)
   - 박스 편집: 빨간 박스 클릭 = 제외, 빈 곳 드래그 = 가릴 영역 추가
   - 도구: 박스 / 브러시 / 금지구역. 브러시와 금지구역은 옆의 칠하기 / 지우기로 골라요
   - 브러시: 칠하기 = 가릴 곳을 칠함, 지우기 = 칠한 자국을 문질러 지움
   - 확대/축소: 박스 편집에서 마우스 휠 (커서 기준). 확대 후 휠 버튼을 누른 채 끌면 화면 이동. +/맞춤/- 버튼도 있어요
   - 금지구역: 칠하기 = 그 곳은 어떤 경우에도 안 가려요, 지우기 = 칠해 둔 금지구역을 걷어냄 (항상 이김. 자동 감지 박스도 이 구역에서는 원본이 남아요)
     Ctrl+Z 또는 획 취소 = 한 획씩 되돌리기. 칠한 내용도 저장 / 검수 체크와 함께 기억돼요
   - 이 그림 저장 / 폴더 전체 실행
   - 검수 체크(단축키 V): 확인이 끝난 그림에 표시해요. 체크하면 그 그림이 (제외한 박스, 직접 그린 박스
     그대로) 결과 폴더에 저장되고, 고친 내용도 기억해요. 표시는 저장되고, 폴더 전체 실행에서 건너뛰어요
     (실행 옵션에서 끌 수 있어요). 목록 위 드롭다운으로 검수 안 한 것만 볼 수도 있고,
     오른쪽 목록의 체크박스로 그림을 열지 않고도 바로 체크할 수 있어요.
     검수 체크를 누르면 다음 그림으로 넘어가요(이미 검수한 그림은 건너뜀). 실행 옵션에서 끌 수 있어요.
4. 끝나면 결과 폴더의 결과보고.txt에서 "감지 없음" 목록을 눈으로 확인해요.

[알아둘 것]
- 자동 감지는 완벽하지 않아요. 공개하기 전에 결과를 꼭 직접 확인하세요.
- 원본 그림은 건드리지 않고, 결과는 별도 폴더에 저장돼요.
- 흰칠(감지)은 내 PC에서만 돌아가요. 그림이 밖으로 나가지 않아요. 인터넷 연결이 필요 없어요.
- "메타데이터 유지"를 끄면(기본) 결과 그림에서 프롬프트/시드가 지워져요. 켜면 PNG의 텍스트
  메타데이터를 그대로 옮겨요. (NAI가 픽셀에 숨겨 넣는 정보는 남지 않아요.)
- 흰칠 옵션은 바꾸는 즉시 이 브라우저에 자동 저장돼요. 자동 스캔 결과와 마지막 폴더는 캐시 폴더에 저장돼요.
- 감지하는 동안 CPU를 코어의 절반쯤 써요.
- 용량만 줄이려면 흰칠 탭 왼쪽 맨 아래 "캐시만 비우기"를 눌러요. 미리 스캔한 감지 결과만 지워지고, 설정과 검수 표시는 그대로예요.
- 처음 상태로 돌리려면 흰칠 탭 왼쪽 맨 아래 "완전 초기화"를 눌러요. 캐시, 저장한 설정, 검수 표시, 팩토리 탭 입력값(API 키 포함)이 지워져요.
  그림 파일과 결과 폴더는 지워지지 않아요.
- 주소(포트)가 바뀌면 브라우저가 저장한 값(API 키 등)이 안 보여요. 그래서 5177로 고정했어요.
  다른 폴더의 같은 프로그램이 켜져 있으면 그 검은 창을 먼저 닫고 다시 실행해 주세요.
